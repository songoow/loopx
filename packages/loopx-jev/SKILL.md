# Optional Jev pilot in an existing coding-host session

Use only when the operator has selected this branch, configured a private finite
run, approved the basis/evidence and chosen shadow or assist. Do not change those
settings to make a task run. Existing Codex/Claude/native Goal ownership stays.

Read `packages/loopx-jev/README.md` for exact commands. Capture one supported real
`quota should-run` or `explore worker-branch-plan` invocation with explicit
registry/runtime/Goal, then run the same command via the optional wrapper.
Always retain the original holds, selected identity and execution instructions.
A zero captured/matched cohort means this call was not assisted, not a failure of
the ordinary work. Report suggestion, actual selection and downstream result
separately. Do not claim the native Agent obeyed a recommendation merely because
the ranking changed. Do not relabel a planner result as an execution receipt.

If config is absent/off, use the original LoopX command directly. Do not request
or inspect a Jev key. On timeout, abstention, stale evidence or revoked mode,
reconcile through the current original owner, never bypass its refusal. Do not
repeat an uncertain billable attempt or create new run directories to evade a
budget. Do not commit captures, private evidence, logs or credentials.

This note is opt-in documentation, not an installed hook. It must not create a
second task scheduler, Stop loop, background worker or authority grant.
